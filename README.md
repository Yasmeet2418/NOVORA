# NOVORA

> **"Learn. Practice. Rise."**

NOVORA is a comprehensive educational and competitive examination preparation platform. It unites an AI-powered study assistant, multi-format note processing, syllabus and PYQ intelligence, and realistic mock exam simulation into one unified workspace.

---

## 🌟 Key Features

### 1. Interactive Academic Dashboard
- **Personalized Header & Goal Switcher**: Switch between Class 6–12 school curricula and competitive exams (JEE Main, NEET UG, NDA, CUET, UPSC, SSC) with one click.
- **Progress Tracking**: Daily study hours progress, topics completed, revisions due today, and overall quiz accuracy.
- **AI Recommendation Engine**: Pinpoints weak subjects and recommends targeted revision tasks and high-weightage PYQs.
- **Upcoming Examination Calendar**: Real official dates and countdowns for JEE Main, NEET UG, NDA, and CBSE Board exams.

### 2. AI Study Assistant — Ask Anything
- **Chat-Style Tutor**: Keep follow-up questions in context, start a fresh chat, and see cited web sources when available.
- **Personalized Answers**: Choose English, Hindi, or Hinglish, plus school or competitive depth and a response style.
- **6 Response Modes**:
  1. *Simple Explanation*: Plain language, everyday analogies, minimal jargon.
  2. *Detailed Academic*: In-depth theoretical rigor with comprehensive context.
  3. *Exam-Oriented*: Marking schemes, board tips, and common examination pitfalls.
  4. *Quick Revision*: Rapid, high-density bulleted review in under 2 minutes.
  5. *Conceptual Understanding*: First-principles deep dive and thought experiments.
  6. *Advanced Problem-Solving*: Rigorous mathematical derivations and step-by-step solutions.
- **Accuracy Guardrails**: The tutor is instructed to show calculation steps and units, avoid invented citations, and state uncertainty. AI answers can still make mistakes and should be checked.
- **AI Availability**: Gemini Flash powers general questions. A small built-in reference covers a few common topics offline; other questions show a clear service error instead of a generic fabricated answer.

### 3. Class-Wise Learning System (Classes 6–12)
- Dedicated curricula for **Class 6, 7, 8, 9, 10, 11, and 12**.
- Supports **CBSE**, **ICSE**, and **State Boards**.
- Each chapter includes:
  - Chapter summary and high-yield key points.
  - Verifiable mathematical and scientific formula sheets.
  - Important definitions.
  - Practice questions (Short Answer and Long Answer with model answers).
  - Interactive MCQ Quizzes with instant scoring, feedback, and explanation.
  - One-click "Add to Revision Planner" scheduling Day 1, 3, 7, 14, and 30 spaced repetitions.

### 4. Smart Notes & File Upload System
- **Supported Formats**: Upload PDF (`.pdf`), Word Documents (`.docx`), Plain Text (`.txt`, `.md`), or Images (`.png`, `.jpg`, `.jpeg`) of handwritten notes, or type notes manually.
- **Client-Side Text Extraction**: Built-in text parsing engine for PDFs and DOCX XML streams, plus simulated note OCR with full student data privacy (no files sent to third parties).
- **10 Structured AI Outputs Generated for Every Note**:
  1. Executive Summary
  2. Chapter Key Points
  3. Important Definitions
  4. Formula Lists
  5. Interactive 3D Flip Flashcards
  6. Self-Grading MCQ Quizzes
  7. Short-Answer Practice Questions with model answers
  8. Long-Answer Questions with marking points
  9. Rapid Revision Sheet
  10. Document Grounding Diagnostics

### 5. Competitive Examination Center
Modular, exam-specific dashboards with verified syllabi, official marking schemes, and durations:
- **Engineering**: JEE Main (+4/-1, 300 marks, 180 mins), JEE Advanced, State CETs.
- **Medical**: NEET UG (+4/-1, 720 marks, 180 questions, 200 mins).
- **Defence**: NDA & NA (Paper 1 Maths +2.5/-0.83, Paper 2 GAT +4/-1.33, 900 marks).
- **University Entrance**: CUET UG (+5/-1, domain tests).
- **Civil Services**: UPSC Civil Services Prelims (GS Paper 1 +2/-0.66, CSAT Paper 2).
- **Banking & Government**: SSC CGL Tier 1 (+2/-0.50), Banking (IBPS/SBI), Railways (RRB).

### 6. Realistic AI Mock Test Generator & NTA CBT / UPSC Simulator
- **JEE Main Practice Forms**: Ten selectable full-length forms, each with 20 MCQs and 5 numerical questions per subject (75 questions / 300 marks total). Questions are original practice material covering recurring, high-yield syllabus topics; they are not reproduced official PYQs. Forms vary question and option order.
- **Official Exam Durations Built-In**:
  - **JEE Main**: Official 3 Hours (180 Minutes), 300 Marks.
  - **NEET UG**: Official 3 Hours 20 Minutes (200 Minutes), 720 Marks.
  - **UPSC Civil Services Prelims**: Official 2 Hours (120 Minutes), 200 Marks.
  - **NDA & NA**: Official 2.5 Hours (150 Minutes), 900 Marks.
  - Practice pacing options: Full Official Duration, Half-Length (90m), 1-Hour Speed Drill (60m), and 30-Min Sprint.
- **Authentic NTA CBT & UPSC Interface**:
  - **Official Top Bar**: Candidate details, Roll No., System ID (C042), and live `HH:MM:SS` countdown timer with pulse warnings under 10 minutes.
  - **Multi-Subject Section Tabs**: Instant switching between Physics, Chemistry, and Mathematics (or Botany & Zoology).
  - **Section B Numerical Value Input (JEE Main)**: On-screen virtual keypad (`0-9`, `.`, `-`, `Backspace`, `Clear`) for entering numerical answers.
  - **Exact Official 5-State NTA Question Palette**:
    1. *Answered* (Green)
    2. *Not Answered* (Red)
    3. *Not Visited* (Gray)
    4. *Marked for Review* (Purple circle)
    5. *Answered & Marked for Review* (Purple circle with green check — evaluated under official rules)
  - **Official Action Buttons**: `Save & Next`, `Save & Mark for Review`, `Clear Response`, and `Mark for Review & Next`.
  - **NTA Submission Summary Dialog**: Summary table of answered, unanswered, and review counts per section before final submission.
  - **Post-Submission Scorecard & Detailed Review**:
    - Subject-by-subject score breakdown table with correct marks (+4) and negative penalties (-1).
    - Estimated NTA Percentile.
    - Full question-by-question review with filter tabs (`All`, `Incorrect Only`, `Unattempted Only`, `Correct Only`).
    - Step-by-step mathematical explanations and "Add to Stuckpoint Recovery" button for every missed concept.

### 7. Exam Priority Radar (High-Weightage Topics)
- Empirical historical analysis based on 70+ official question papers (2018–2024).
- Chapters ranked into Tier 1 (High Yield) and Tier 2 (Moderate Yield).
- Displays average questions per shift, historical frequency, common student traps, and high-yield concepts.
- Transparent methodology: explicitly identifies historical trends without making false guarantees.

### 8. PYQ Intelligence Engine
- Identifies exact repeated questions and recurring "conceptual twins" across years.
- Shows verified shift appearances (e.g. JEE Main 2019, 2021, 2023, 2024).
- Provides speed shortcuts, common pitfalls to avoid, and interactive similar practice questions.

### 9. AI Doubt Solver with Diagnostics
- Submit questions via text or photo/diagram upload.
- Delivers step-by-step derivations, applied theorems, shortcut methods, and a diagnostic breakdown of **why the incorrect options are wrong**.

### 10. AI Personalized Study Planner
- Dynamic timetable generator based on available daily study hours and weak topics.
- Generates a 7-day schedule with daily task checklists, spaced repetition sessions, and mock test milestones.

### 11. External Educational Resources Discovery
- Curated index of official, verified free portals: NTA (`nta.ac.in`), CBSE Academic (`cbseacademic.nic.in`), NCERT (`ncert.nic.in`), UPSC (`upsc.gov.in`), SSC (`ssc.gov.in`), and SWAYAM (`swayam.gov.in`).
- Live Google Custom Search integration for discovering official sample papers and answer keys.

### 12. Performance Analytics & Memory Retention
- Ebbinghaus Forgetting Curve tracking and Spaced Repetition adherence.
- Quiz score trends, topic mastery rates, and mock test score progressions.

### 13. Stuckpoint Recovery (`/#/recovery`)
- Preserved from the original learning platform.
- Dedicated recovery area to review concepts flagged as difficult or missed during quizzes until mastered.

## 🚀 Quick Start Guide

### Option 1: Double-Click Launcher (Windows)
Double-click `start.bat` in the project root folder. It will launch the local HTTP server and open the application in your browser at `http://localhost:3000`.

### Option 2: Running with Node.js
```bash
# Start the local server
npm start
# Or directly:
node server.js
```
Then navigate to `http://localhost:3000` in your browser.

### Option 3: Direct Browser Launch
Open `index.html` directly in any modern browser (Google Chrome, Microsoft Edge, Opera, Mozilla Firefox, Safari).

## 🔒 Privacy & Architecture
- **Supabase Accounts**: Email/password sign-up, sign-in, and logout. Learning data is cached per account in the browser and synced to that user's protected Supabase row; row-level security prevents accounts from reading or changing another user's row.
- **Supabase Setup**: Run [`supabase/schema.sql`](./supabase/schema.sql) in the Supabase SQL Editor. In Supabase Authentication settings, set the Site URL and allowed redirect URLs to your deployed site; configure email confirmation as desired.
- **Deployment**: Local code changes are not live automatically. Push the changes to the connected GitHub branch and wait for Netlify/Railway to finish its deployment before testing the live URL.
- **Hosted AI Setup**: Set a valid `GEMINI_API_KEY` in the hosting provider's environment variables for shared AI access. Never commit the key. Users can alternatively enter their own Gemini key in **Settings → AI & Search Provider Integrations**.
- **Local Storage**: The app keeps an account-specific browser cache for responsiveness and offline continuity. AI provider API keys remain local and are excluded from cloud sync.
- **Zero Cloud Leakage**: Document parsing and text extraction occur strictly on the client side.
- **Configurable External APIs**: Gemini API keys and Google Search API keys (if used) remain stored on the local browser and are not uploaded to Supabase.
